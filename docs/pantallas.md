# Pantallas (borrador)
1. **Inicio**: mapa con unidades en vivo (color: verde cupo, rojo lleno), buscador de ruta.
2. **Ruta**: recorrido, paradas, próximas unidades.
3. **Unidad**: conductor, estado, última actualización, "reportar".
4. **Modo conductor**: ruta activa, botones grandes Recorrido / Cupo / Lleno, GPS activo.
5. **Reportar**: "lo vi aquí", "va lleno", "no pasa".
